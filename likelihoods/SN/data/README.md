# Shared supernova covariance

`Pantheon+SH0ES_STAT+SYS.cov` is shared by the Pantheon+ and Pantheon+SH0ES
likelihoods and is available to the DDR plotting helpers. Its contents are
unchanged from the released Pantheon+SH0ES covariance.

The first line gives the matrix dimension (1701); the remaining values store
the full covariance in row-major order. Data references and column definitions
are described in [the Pantheon+ data README](../Pantheon_Plus/data/README).
